# Task List รอบ 6: Friendly & Frictionless Commute UX (US-29..US-41)

อ้างอิง: `docs/requirements-round6-ba.md` (ไม่แก้ tasks.md เดิม) ขนาด: S = ครึ่งรอบ, M = 1 รอบ, L = 1.5-2 รอบ

## คำตัดสิน PM (Q1-Q10)
- Q1 คนขับมาถึงจุดรับ: ปุ่มเดียว "ถึงจุดรับแล้ว" = ส่งข้อความสำเร็จรูป "คนขับมารอที่จุดรับแล้วนะ" ในแชทเดิม + แจ้งเตือนในแอป/local notification ฝั่ง Rider; ไม่มีสถานะทริปใหม่ ไม่มี DB ใหม่; throttle 1 ครั้ง/นาที; เหตุผล: ไม่แตะ state machine, ทำได้ในรอบนี้
- Q2 preset: เก็บในเครื่องเท่านั้น (secure storage ผูก user id), ล้างเมื่อออกจากระบบ/ลบบัญชี, ซิงก์ server = นอกรอบนี้ (ต้องผ่านกฎหมายก่อนเสมอ); เหตุผล: ที่อยู่บ้านอ่อนไหวตาม PDPA
- Q3 การ์ด deck: ตัวอักษรย่อ + ชื่อเล่น; รูปโปรไฟล์แสดงหลังจับคู่ตอบรับเท่านั้น (Match Moment/แชท/UnifiedRide) คง US-22. **ขัดกับร่างของผู้ใช้ (ร่างต้องการรูปบนการ์ด) = ผลกระทบต่อผู้ใช้โดยตรง orchestrator ต้องแจ้งผู้ใช้**; ถ้าผู้ใช้ยืนยันให้แสดงรูปบนการ์ด ต้องเปลี่ยนกฎ US-22 + ผ่านฝ่ายกฎหมาย + แก้ `find_matches`/signed URL policy (ไม่ทำรอบนี้)
- Q4 เก็บหน้ารายการ nearby เดิมเป็นมุมมองทางเลือก (ปุ่มสลับ deck/รายการ) เพื่อ a11y และการเปรียบเทียบ
- Q5 ข้อความถึงที่หมาย: ถ้าปลายทางของทริปตรงกับ preset "บ้าน" (เทียบบนเครื่อง ไม่ส่ง server; ใช้รัศมีเดียวกับที่ตั้งค่าเมื่อสร้างจาก quick card) = "ถึงบ้านปลอดภัยแล้ว 🎉 ขอบคุณเพื่อนร่วมทาง"; อื่น ๆ (รวม Peer/ไม่มี preset) = "ถึงที่หมายปลอดภัยแล้ว 🎉 ขอบคุณเพื่อนร่วมทาง"; label สไลเดอร์ถึงแล้วใช้ตรรกะเดียวกัน ("สไลด์เมื่อถึงบ้านปลอดภัย" / "สไลด์เมื่อถึงที่หมายปลอดภัย")
- Q6 Undo: ปัดขวา/💚 ส่งทันที (ไม่หน่วง) แล้ว undo 5 วินาที = ยกเลิกคำขอ pending ผ่านช่องทางเดิม; คำขอที่ undo แล้วไม่นับเพดานคำขอค้าง (ไม่ pending แล้ว) แต่ **throttle การส่งยังนับ** (ป้องกันส่ง-ยกเลิกรัว ๆ); ถ้าอีกฝ่ายตอบรับไปแล้ว undo ต้องไม่ยกเลิกการจับคู่ + แจ้งสุภาพ; ปุ่ม "เลิกชวน" ปิดไว้ระหว่างรอผลส่ง
- Q7 R5-1: ขยาย `find_matches` (P1, /db-architect) คืนค่ารวมแบบไม่ระบุตัวตน ควบคุมด้วย `review.show_in_search`, รีวิวเปิดเผย ≥ 3, ห้ามคืน user id; ถ้า DB ไม่ทัน เลื่อนเฉพาะ US-36 (US-34/35 ไม่ถูกบล็อก; UI ต้องเขียนให้ซ่อนช่องเมื่อไม่มีค่า)
- Q8 ตัวเลือกเวลา: "ตอนนี้เลย" + 17:30 + 18:00 ค่าคงที่ (ตัดค่าที่ผ่านไปแล้วของวันนี้ออก; ถ้าเหลือ < 3 ตัวเลือก ให้เติมเป็นช่วงถัดไปจากเวลาปัจจุบัน ปัดขึ้น 30 นาที); ไม่เรียนรู้พฤติกรรม
- Q9 ปุ่ม 1 แตะ: เฉพาะ car (Rider/Driver); Peer ใช้ wizard เดิม
- Q10 ปุ่มนำทางภายนอกที่ Half ใช้กติกา US-24 เดิมทั้งหมด (รวม dialog แจ้งครั้งแรก, คำเตือนขับรถ, ซ่อนปุ่มจุดรับเมื่อ ≤ 50 ม.)
- ต้องอัป requirements: ใช่ (เล็กน้อย) รายการให้ BA แก้ `requirements-round6-ba.md`: (1) US-35: ระบุ undo = ส่งทันทีแล้วยกเลิก, ไม่นับเพดานแต่นับ throttle, ห้ามยกเลิกคู่ที่ตอบรับแล้ว (2) US-31 + US-40: ข้อความ/label ถึงที่หมาย 2 รูปแบบ (บ้าน/ทั่วไป) ตาม Q5 (3) US-39: กติกาตัวเลือกเวลาตาม Q8 และ car-only ตาม Q9 (4) US-34: บันทึกว่า Q3 ต่างจากร่างผู้ใช้โดยตั้งใจ (5) สมมติฐาน 7, 2, 10, 15 เปลี่ยนสถานะเป็น "PM ยืนยันแล้ว" และปิด Q1-Q10
