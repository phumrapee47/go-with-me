# Requirements รอบ 6: การปรับปรุง UX/UI เชิงประสบการณ์เพื่อน (Friendly & Frictionless Commute UX)

## สถานะเอกสารและเป้าหมายหลัก
- **สถานะ:** แผนความต้องการโดยละเอียด (Detailed UX Specification) มุ่งเน้นการแก้ปัญหา Friction และความซับซ้อนของการใช้งานจริง
- **แก่นของแอป:** **"กลับด้วยกันมั้ย"** — การหาเพื่อนร่วมทางกลับบ้านในฟีลลิ่งเพื่อนร่วมทางที่อบอุ่นและไว้วางใจได้ ไม่ใช่แอปเรียกรถรับจ้างหรือระบบงานขนส่งทางการ
- **เป้าหมายประสบการณ์ผู้ใช้ (UX Goal):** ลดจำนวนครั้งในการกด (Fewer Clicks), กำจัด Dialog ซ้ำซ้อน, รวมหน้าจอการเดินทางให้เบ็ดเสร็จแบบแอปสมัยใหม่ (Unified Ride Sheet) และนำเสนอเพื่อนร่วมทางในรูปแบบการค้นหาที่น่าใช้งาน (Card Deck Discovery)

---

## สรุปรายการงานที่ต้องทำทั้งหมด (Detailed Breakdown)

### 1. Unified In-Ride Experience (รวมหน้าเดินทางให้เป็นหนึ่งเดียวแบบ Grab)

* **1.1 รวมหน้าจอเดินทางหลักเป็น `UnifiedRideScreen`**
  * **ปัญหาเดิม:** ผู้ใช้ต้องกดสลับไปมาระหว่าง `ActiveTripScreen` (ดูข้อมูล), `LiveMapScreen` (ดูแผนที่สด) และหน้าแชท
  * **สิ่งที่ต้องทำ:**
    * ให้แผนที่สดแบบ Full-screen เป็นพื้นหลังถาวร แสดงพิกัดตนเอง, คู่เดินทาง, เส้นทาง และจุดรับส่ง
    * สร้าง `DraggableScrollableSheet` ด้านล่างที่ปรับได้ 3 ระดับ:
      1. *Collapsed (ย่อเล็กสุด):* แสดงรูปคู่เดินทาง, ชื่อเล่น, เวลา ETA ถึงจุดนัดพบ/ปลายทาง, และแถบปุ่มสไลด์หลัก
      2. *Half-expanded (กึ่งกลาง):* แสดงข้อมูลรถ (ทะเบียน/รุ่น เมื่อมีสิทธิ์), ชิปแชทด่วน, ปุ่มเปิดแอปนำทางภายนอก (Google Maps/Apple Maps)
      3. *Full (เต็มจอ):* รายละเอียดทริปทั้งหมด, ปุ่มแชร์ทริปให้คนใกล้ชิด, และปุ่มฉุกเฉิน SOS
* **1.2 นำเข้าวิดเจ็ต `SwipeToConfirmSlider` (Slide-to-Action)**
  * **ปัญหาเดิม:** มี Pop-up Confirm Dialog เด้งถามซ้ำซาก ("แน่ใจหรือไม่ว่าออกเดินทาง?", "แน่ใจหรือไม่ว่าขึ้นรถแล้ว?", "แน่ใจหรือไม่ว่าถึงแล้ว?")
  * **สิ่งที่ต้องทำ:**
    * ตัด Confirm Dialog ทั้งหมดออกจากการเปลี่ยนสถานะปกติ
    * ใช้แถบเลื่อนสไลด์จากซ้ายไปขวา (Slide to Action) เพื่อป้องกันการกดพลาดโดยไม่ตั้งใจ:
      * **คนขับก่อนออก:** *`สไลด์เพื่อเริ่มออกเดินทาง`* (Start Trip)
      * **คนนั่งเมื่อถึงจุดรับ:** *`สไลด์เพื่อขึ้นรถแล้ว`* (Boarded)
      * **เมื่อถึงปลายทาง:** *`สไลด์เมื่อถึงบ้านปลอดภัย`* (Arrived)
* **1.3 ระบบ Geofence Proximity Highlight**
  * เมื่อพิกัด GPS ของผู้ใช้อยู่ห่างจากจุดหมายปลายทางน้อยกว่า 150 เมตร ให้เปลี่ยนสีแถบสไลด์เป็นสีเขียวเด่นพร้อมข้อความแนะนำทันที เพื่อให้แตะสไลด์จบทริปได้ในเสี้ยววินาที

### 2. Commute Discovery Flow (ค้นหาเพื่อนร่วมทางสไตล์ Card Deck)

* **2.1 หน้ารวมการ์ดเพื่อนร่วมทาง `CommuteCardDeck`**
  * **ปัญหาเดิม:** หน้า Nearby ปัจจุบันเป็นรายการตารางกึ่งราชการ (blurred list) ต้องกดเข้าไปดูรายละเอียดทีละคน
  * **สิ่งที่ต้องทำ:**
    * แสดงผลเพื่อนร่วมทางที่เข้าเกณฑ์ในรูปแบบการ์ดเดี่ยวขนาดใหญ่ (Card Deck)
    * องค์ประกอบบนการ์ด:
      * รูปโปรไฟล์และชื่อเล่นเด่นชัด (หรือตัวอักษรย่อ)
      * ป้ายสถานะยืนยันตัวตน / สถาบัน / บริษัท (เช่น "นิสิตจุฬาฯ", "บุคคลทั่วไป")
      * ข้อมูลความเข้ากันได้: "ทางเดียวกัน ~85%", "เวลาเลิกงาน 17:30 น."
      * หากเป็น Driver: แสดงจำนวนที่นั่งว่าง และไอคอนรถ
    * การโต้ตอบ (Interactions):
      * **ปัดซ้าย (Swipe Left)** หรือกดปุ่ม ✕: ข้ามไปดูคนถัดไป
      * **ปัดขวา (Swipe Right)** หรือกดปุ่ม 💚: **"ชวนกลับด้วยกัน"**
* **2.2 โมดอลเฉลิมฉลองเมื่อจับคู่สำเร็จ (Match Moment Modal)**
  * เมื่ออีกฝ่ายตอบรับคำชวน แสดงแอนิเมชันป๊อปอัปสไตล์เพื่อน: *"ได้เพื่อนกลับบ้านแล้ว! 🎉"*
  * แสดงรูปคู่พร้อม 2 ปุ่มแอ็กชันทันที:
    1. **"ทักทายนัดจุดรับ"** (เปิดหน้าแชทพร้อมข้อความทักทายอัตโนมัติ)
    2. **"ดูแผนที่การเดินทาง"** (เข้าสู่หน้า Unified Ride Screen ทันที)

### 3. Quick Commute Intent (สร้างทริปกลับบ้านใน 1 แตะ)

* **3.1 ระบบจดจำสถานที่โปรด (Home & Commute Preset)**
  * บันทึกพิกัด "บ้าน" (Home) และ "จุดเริ่มประจำ" (Campus/Office) ไว้ใน Preferences
* **3.2 วิดเจ็ต 1-Tap บนหน้าแรก (Home Screen Quick Widget)**
  * **ปัญหาเดิม:** ต้องผ่าน Wizard 3 หน้าจอ (Step 1 พิกัด $\rightarrow$ Step 2 บทบาท/รถ $\rightarrow$ Step 3 สรุป)
  * **สิ่งที่ต้องทำ:**
    * มีการ์ดแนะนำบนหน้าหลัก: *"กำลังจะกลับบ้านใช่ไหม?"*
    * แสดงตัวเลือกเวลากลับบ้าน (เช่น "ตอนนี้เลย", "17:30", "18:00")
    * สวิตช์สลับบทบาท `[ คนนั่ง / ขับรถเอง ]` (จดจำค่าล่าสุดอัตโนมัติ)
    * กดปุ่มเดียว: **"หาเพื่อนกลับบ้าน"** $\rightarrow$ บันทึกทริปและพาไปหน้า Card Deck ทันทีโดยไม่ต้องกรอกพิกัดซ้ำ

### 4. ปรับเปลี่ยนคำและโทนเสียงให้เหมือนเพื่อน (Friendly Micro-copy)

* ปรับปรุงข้อความใน Localization ([`strings_trip.dart`](file:///c:/Users/Asus/Documents/GOWITHME/lib/core/l10n/strings_trip.dart), [`strings_roles.dart`](file:///c:/Users/Asus/Documents/GOWITHME/lib/core/l10n/strings_roles.dart)):
  * **ขอร่วมทาง:** จาก *"ส่งคำขอการจับคู่"* $\rightarrow$ *"ชวนเพื่อนแล้ว! รอเพื่อนตอบแป๊บนะ"*
  * **ตอบรับ:** จาก *"ยอมรับการจับคู่"* $\rightarrow$ *"ไปด้วยกันเลย!"*
  * **คนขับมาถึง:** จาก *"ผู้ขับขี่มาถึงจุดนัดพบแล้ว"* $\rightarrow$ *"คนขับมารอที่จุดรับแล้วนะ"*
  * **ขึ้นรถ:** จาก *"ยืนยันการขึ้นยานพาหนะ"* $\rightarrow$ *"ขึ้นรถเรียบร้อยแล้ว 🚗"*
  * **ถึงที่หมาย:** จาก *"เสร็จสิ้นการเดินทาง / ยืนยันการมาถึง"* $\rightarrow$ *"ถึงบ้านปลอดภัยแล้ว 🎉 ขอบคุณเพื่อนร่วมทาง"*
