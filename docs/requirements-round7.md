## รายละเอียด User Stories & Acceptance Criteria

### US-42: การแจ้งเตือนพุชระยะไกล (Remote Push Notifications) [P0]
As a ผู้ใช้ (ทั้งคนขับและคนนั่ง),
I want ได้รับการแจ้งเตือนบนมือถือเมื่อมีเพื่อนชวนเดินทางหรือตอบรับคำชวน แม้จะปิดหรือพักแอปอยู่,
so that ไม่พลาดการนัดหมายและตอบกลับได้ทันท่วงที

#### Acceptance Criteria:
- [ ] **การลงทะเบียนและถอน Token (Device Token Lifecycle):**
  - ขอสิทธิ์แจ้งเตือนเมื่อเข้าสู่ระบบหรือเมื่อสร้างทริปแรก พร้อมคำอธิบายภาษาไทยที่ชัดเจน
  - บันทึก Device Token ลงตาราง `device_tokens (user_id, token, platform, updated_at)`
  - เมื่อผู้ใช้ออกจากระบบ (Sign Out) หรือลบบัญชี Token ต้องถูกลบออกจากฐานข้อมูลทันที
- [ ] **นโยบาย Zero-PII Payload เด็ดขาด:**
  - ข้อความแจ้งเตือนที่ส่งผ่าน FCM/APNs **ต้องไม่มี** ชื่อ-นามสกุล, เบอร์โทรศัพท์, ทะเบียนรถ, พิกัด หรือข้อความแชทจริง
  - ส่งเฉพาะรหัสประเภทและข้อความภาษาไทยมาตรฐาน:
    - มีคนชวน: `"มีเพื่อนชวนกลับด้วยกันแล้ว! แตะเพื่อดู"`
    - ตอบรับแล้ว: `"เพื่อนตอบรับคำชวนแล้ว! ไปด้วยกันเลย"`
    - แชทใหม่: `"มีข้อความใหม่เกี่ยวกับจุดนัดรับ"`
    - คนขับถึงจุดรับ: `"คนขับมารอที่จุดรับแล้วนะ"`
    - ยกเลิก: `"เพื่อนร่วมทางได้ยกเลิกการเดินทาง"`
- [ ] **การนำทางเมื่อแตะการแจ้งเตือน (Deep Linking):**
  - แตะการแจ้งเตือนแล้วแอปเปิดไปยังหน้าที่เกี่ยวข้องทันที (เช่น หน้า Card Deck สำหรับคำขอใหม่ หรือหน้า Unified Ride Screen สำหรับทริปที่ตอบรับแล้ว)
  - หาก session หลุด ให้กลับไปหน้าเข้าสู่ระบบอย่างปลอดภัย

### US-43: ปักหมุดเลือกจุดนัดรับบนแผนที่ (Interactive Meeting Point Pin Drop) [P0]
As a คนขับหรือคนนั่งที่จับคู่กันแล้ว,
I want ปักหมุดเลือกจุดขึ้นรถที่สะดวกบนแผนที่และกดยืนยันร่วมกัน,
so that ทั้งสองฝ่ายนัดพบกันได้ถูกต้องโดยไม่ต้องเสียเวลาพิมพ์อธิบายทางแชท

#### Acceptance Criteria:
- [ ] **การเลือกจุดบนแผนที่ (Interactive Map Selection):**
  - ในหน้า Unified Ride Screen หรือหน้ารายละเอียดการจับคู่ มีปุ่ม *"เลือกจุดนัดรับบนแผนที่"*
  - เปิดหน้าต่างแผนที่ให้ลากหมุดไปยังจุดที่จอดรับได้สะดวกตามแนวเส้นทาง (Route Corridor)
  - ระบบทำการ Snap หมุดเข้ากับถนนหลักที่ปลอดภัย และคำนวณระยะเบี่ยงของคนขับไม่ให้เกินเกณฑ์
- [ ] **การเสนอและตอบรับ (Propose & Confirm):**
  - ฝ่ายใดฝ่ายหนึ่งสามารถเสนอจุดรับได้ $\rightarrow$ อีกฝ่ายเห็นหมุดแนะนำบนแผนที่พร้อมปุ่ม *"ตกลงเจอกันตรงนี้"*
  - เมื่อกดยืนยัน หมุดจะกลายเป็นจุดนัดรับอย่างเป็นทางการ (`agreed_pickup_point`) ทันที
  - ทั้งสองฝ่ายเห็นปุ่ม *"นำทางด้วยแอปแผนที่"* มุ่งตรงไปยังจุดนัดรับนี้ได้ทันที

### US-44: แท็กไลฟ์สไตล์และสเตตัสประจำวัน (Commute Vibe Tags & Daily Mood) [P1]
As a ผู้เดินทาง,
I want ระบุสไตล์การเดินทางและข้อความสั้นๆ ประจำวันบนการ์ดของฉัน,
so that คนที่กำลังหาเพื่อนร่วมทางเข้าใจ Vibe และเลือกเดินทางด้วยกันได้อย่างสบายใจ

#### Acceptance Criteria:
- [ ] **แท็กไลฟ์สไตล์ (Commute Vibe Tags):**
  - ให้เลือกได้สูงสุด 3 แท็กจากรายการที่กำหนด (Allowlist):
    - สำหรับคนขับ: `#เปิดแอร์เย็น`, `#เปิดเพลงฟังเพลิน`, `#ขับนิ่มไม่ซิ่ง`, `#ไม่สูบบุหรี่`, `#มีที่เก็บกระเป๋า`
    - สำหรับคนนั่ง/ทั่วไป: `#คุยเก่ง`, `#ขอพักสายตาเงียบๆ`, `#ฟังเพลงสากล`, `#สายประหยัด`, `#พร้อมแชร์เรื่องเล่า`
  - แสดงแท็กเป็นชิปมนโทนสีพาสเทลบน [CommuteCardDeck](file:///c:/Users/Asus/Documents/GOWITHME/lib/features/matching/presentation/commute_card_deck.dart)
- [ ] **สเตตัสประจำวัน (Daily Commute Mood):**
  - ข้อความสั้นไม่เกิน 35 ตัวอักษร เช่น *"วันนี้เหนื่อยมาก อยากรีบกลับนอน"*, *"วันนี้กลับชิลๆ คุยได้"*
  - สเตตัสจะรีเซ็ตอัตโนมัติเมื่อจบทริป หรือผ่านไป 24 ชั่วโมง เพื่อไม่ให้ค้างข้ามวัน

### US-45: ตัวกรองความปลอดภัย: Women-Only [P1]
As a ผู้ใช้ที่ต้องการความปลอดภัยเป็นพิเศษ,
I want เลือกเดินทางเฉพาะผู้หญิงด้วยกัน,
so that รู้สึกอุ่นใจและมั่นใจในความปลอดภัยสูงสุด

#### Acceptance Criteria:
- [ ] **ตัวกรองเฉพาะผู้หญิง (Women-Only Matching):**
  - เปิดใช้งานได้เฉพาะผู้ใช้ที่ระบุเพศหญิงและยินยอมเปิดเผยข้อมูลนี้เพื่อการจับคู่
  - สวิตช์: *"ต้องการเพื่อนร่วมทางเฉพาะผู้หญิง"*
  - ระบบจะจับคู่เมื่อ **ทั้งสองฝ่าย** เปิดสวิตช์นี้และเป็นผู้หญิงทั้งคู่เท่านั้น
  - ป้ายบนการ์ดแสดงสัญลักษณ์ `[ Women-Only ]` โทนสีสุภาพชัดเจน

### US-46: โหมดมืดและแผนที่มืดสมบูรณ์แบบ (Dark Mode & Night Map Tiles) [P1]
As a คนขับที่วางมือถือหน้ารถตอนกลางคืน,
I want ให้ทั้งตัวแอปพลิเคชันและแผนที่เปลี่ยนเป็นโทนสีเข้ม (Dark Mode & Dark Map Tiles),
so that แสงสว่างสีขาวไม่สะท้อนกระจกหน้ารถ และไม่แยงตาระหว่างขับขี่

#### Acceptance Criteria:
- [ ] **การสลับชุดภาพแผนที่ (Tile Layer Switching):**
  * เมื่อเปิดใช้งาน Dark Mode ตัว [TileLayer](file:///c:/Users/Asus/Documents/GOWITHME/lib/core/map/app_map.dart#L117) จะสลับ `urlTemplate` ไปใช้ CartoDB Dark Matter:
    `https://a.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}.png`
  * เมื่อกลับสู่ Light Mode จะสลับกลับไปใช้ OpenStreetMap มาตรฐาน
- [ ] **การปรับแต่งเส้นทางและหมุด (Route Casing & Marker Contrast):**
  * เส้นทาง Polyline ของคนขับ (สีส้มทอง) และคนนั่ง (สีฟ้า) บนแผนที่มืด ต้องเพิ่มเส้นขอบสีสว่าง (White/Light Casing กว้าง 1.5–2 dp) เพื่อให้เส้นทางเด่นชัด ไม่จมหายไปกับพื้นถนนสีดำ
  * หมุดตำแหน่งรถและคนเดินมีเงาสะท้อน (Subtle Glow / Drop Shadow) เพื่อให้อ่านง่ายในที่มืดตามเกณฑ์ WCAG AA
- [ ] **การสลับอัตโนมัติ (Auto-Night Mode):**
  * มีตัวเลือกในหน้าตั้งค่า: `[ ตามระบบ (System) / สว่างตลอด (Light) / มืดตลอด (Dark) / มืดอัตโนมัติตามเวลา (18:00 - 06:00) ]`

### US-47: สรุปผลกระทบเชิงบวกและสัมผัสสั่น (Shared Impact & Haptics) [P2]
As a ผู้ร่วมเดินทางที่ถึงบ้านปลอดภัยแล้ว,
I want เห็นข้อมูลว่าการเดินทางร่วมกันครั้งนี้ช่วยโลกอย่างไร พร้อมส่งคำขอบคุณให้เพื่อน,
so that รู้สึกดีและมีกำลังใจในการใช้บริการเป็นประจำ

#### Acceptance Criteria:
- [ ] **การ์ดสรุปหลังจบทริป (Shared Impact Card):**
  - แสดงผลหลังสไลด์ถึงที่หมาย:
    - *"คุณและ [ชื่อเล่นเพื่อน] ร่วมกันลดก๊าซคาร์บอนไดออกไซด์ไป ~1.4 kg CO₂ ในการเดินทางครั้งนี้!"*
    - คำนวณจากระยะทางที่เดินทางร่วมกัน $\times$ อัตราการปล่อยเฉลี่ยของรถยนต์ส่วนบุคคล (~120 g/km)
  - ปุ่มส่งสติกเกอร์ขอบคุณเพื่อน 1 แตะ (เช่น "ขอบคุณมากนะ!", "ขับปลอดภัยครับ", "เพลงเพราะมาก")
- [ ] **Haptic Feedback (ระบบสั่นตอบสนอง):**
  - สั่นเบาๆ (Selection click) เมื่อลากการ์ด Card Deck
  - สั่นยืนยัน (Heavy impact) เมื่อสไลด์ [SwipeToConfirmSlider](file:///c:/Users/Asus/Documents/GOWITHME/lib/core/widgets/swipe_to_confirm_slider.dart) สำเร็จที่ 95%
  - เคารพการตั้งค่า "ลดการเคลื่อนไหวและการสั่น" ของระบบปฏิบัติการ
